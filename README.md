# Asya_WebP_to_PNG_or_JPG_saver_Chrome_Extension
This Chrome browser extension allow to save any images from any sites that originaly are in WebP file format on your hard drive in *.png or *.jpg format in just 2 clicks! Most easy and convenient way to grab images from sites.

I. Installation:

1. Download and unpack from archive folder 'Asya_WebP_to_PNG_or_JPG_saver_Chrome_Extension-main', save it any folder you please
2. Start Chrome browser then press settings (3 dots) in upper right corner ->Extensions. Or simply enter 'chrome://extensions" in address bar and press Enter
3.Once in Extensions page toggle on Developer mode in upper right then press "load unpacked" in right top and navigate to your folder 'Asya_webp_to_png_or_jpg_saver_chrome_extension.crx'then press 'Select folder'

II. Usage:

On any site where you want to download image just click on image with right mouse button and in opened context menu select 'Save image as PNG or JPG'
That's all!
